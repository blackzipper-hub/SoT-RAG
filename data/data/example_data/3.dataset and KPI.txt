MultiNLI (Multi-Genre Natural Language Inference)

名称：Multi-Genre Natural Language Inference (MultiNLI)

任务类型：自然语言推理（Natural Language Inference, NLI） / 文本蕴含识别

来源：

构造方式：从已有文本中抽取前提句（premise），由人工标注者编写假设句（hypothesis）

数据特点：覆盖多种体裁（genre），包括口语与书面语，支持跨体裁（cross-genre）评测

背景：是 SNLI 的扩展，用于评测句子表示的泛化能力

用途：作为 RepEval 2017 Workshop 的共享任务数据集

规模：

训练集：392,702

验证集（matched）：9,815

验证集（mismatched）：9,832

字段：

promptID: 整数，前提句唯一 ID

pairID: 字符串，前提-假设对唯一 ID

premise: string，前提句

premise_parse / premise_binary_parse: 句法解析（Stanford PCFG Parser 3.5.2）

hypothesis: string，假设句

hypothesis_parse / hypothesis_binary_parse: 句法解析（Stanford PCFG Parser 3.5.2）

genre: string，文本体裁（如 government, fiction 等）

label: 分类标签，取值：

entailment (0)

neutral (1)

contradiction (2)

-1 表示无 gold label（需过滤）

示例：

{
  "promptID": 31193,
  "pairID": "31193n",
  "premise": "Conceptually cream skimming has two basic dimensions - product and geography.",
  "hypothesis": "Product and geography are what make cream skimming work.",
  "genre": "government",
  "label": 1
}


标注：

✅ premise 来自已有文本（新闻、政府文件、小说、对话等）

✅ hypothesis 由人工撰写

✅ 标签由人工标注，三分类（entailment, neutral, contradiction）

适用指标：

准确率（Accuracy）

宏平均 F1（Macro-F1，可选）

许可信息：

大部分语料遵循 OANC 许可（可自由使用、修改和共享）

FICTION 部分：部分作品采用 CC BY-SA 3.0 或 CC BY 3.0 许可，其余为美国公有领域作品

squad-v1.1-t5-question-generation

名称：squad-v1.1-t5-question-generation

任务类型：问题生成（Question Generation, QG）

来源：

原始数据：改造自 SQuAD v1.1（Stanford Question Answering Dataset）

问题生成格式：基于 T5 模型设计，采用 All Questions in One Line (AQOL) 格式

问题与答案：原始 SQuAD 问答由 Amazon Mechanical Turk 工人撰写

规模：

训练集：18,896

验证集：2,067

（不包含测试集划分）

字段：

context: string，输入上下文文本（前缀为 "generate questions:"）

question: string，对应生成的问题集合，以 {sep_token} 分隔

示例：

{
  "context": "generate questions: This is a test context.",
  "question": "Is this a test? {sep_token} Is this another Test {sep_token}"
}


标注：

✅ 问答数据原始来自 SQuAD，由 Amazon Mechanical Turk 工人编写

✅ 重新组织为多问题拼接的生成目标，适配 T5 模型

⛔ 没有额外分层标注

适用指标：

BLEU, ROUGE, METEOR（用于文本生成质量评估）

可扩展使用 BERTScore 等生成指标
